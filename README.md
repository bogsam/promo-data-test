# Laravel Modulith Template

Шаблон для старта модульного Laravel-приложения с API-first подходом.

## Что внутри

- модульная структура в `src/app/Modules`
- PostgreSQL как основная база данных
- Redis для кэша и очередей
- тесты на SQLite in-memory

## Быстрый старт

1. Скопируй переменные окружения и заполни значения под себя.
2. Подними контейнеры через `make up`.
3. Выполни миграции и сиды через `make migrate-fresh`.

## Полезные команды

- `make up` - поднять окружение
- `make down` - остановить окружение
- `make migrate` - выполнить миграции
- `make migrate-fresh` - пересоздать базу и прогнать сиды
- `make test` - запустить тесты
- `make qa` - прогнать форматирование, статический анализ и тесты

## Структура

- `src/` - Laravel-приложение
- `docker/` - Docker-обвязка
- `docs/` - проектные заметки и требования

## Примечание

Темплейт задуман как API-only. Веб-роуты и стартовая страница не входят в базовый набор.
