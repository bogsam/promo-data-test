# Promo Data Test

Тестовый Laravel-проект для формирования CSV-отчёта по товарам выбранной категории за последние 7 дней с асинхронной обработкой через очередь и журналированием выполнения.

## Что есть в проекте

- консольная команда для запуска отчёта
- очередь для фоновой генерации CSV
- страница контроля процессов
- миграции для структуры базы данных

## Стек

- PHP 8.4
- Laravel 13
- PostgreSQL 15
- Node.js/npm для сборки Vite-ассетов
- Redis

## Установка

1. Склонируйте репозиторий.
2. Перейдите в корень проекта.
3. Скопируйте env-файлы из примеров:

```bash
cp .env.example .env
cp src/.env.example src/.env
```

4. Для первого запуска поднимите проект командой:

```bash
make install
```

Эта команда:
- собирает и запускает Docker-контейнеры;
- ставит зависимости через Composer;
- выполняет `php artisan migrate:fresh --seed`;
- поднимает приложение по адресу из `HTTP_PORT` в `.env`.

5. Сгенерируйте локальный ключ Laravel-приложения:

```bash
docker compose exec app php artisan key:generate
```

6. Соберите фронтовые ассеты:

```bash
cd src
npm ci
npm run build
cd ..
```

## Архитектура

Код разбит на модули с разделением на доменный, прикладной и инфраструктурный слои.
- `Reports` отвечает за процесс формирования отчёта, статусы, генерацию CSV и страницу контроля.
- `Catalog` отвечает за данные каталога: товары, производителей и цены. Для тестового задания они объединены в один модуль, потому что используются как единый источник данных для отчёта.
- `Shared` содержит общие контракты, DTO и value objects, которые используются несколькими модулями.
- `Core` содержит базовую инфраструктуру Laravel: провайдеры, маршруты и общие системные настройки.

## Формирование отчёта

Команда `report:generate` создаёт запись процесса и отправляет job в Redis-очередь. CSV формируется сервисом `queue-worker`.

```bash
docker compose exec app php artisan report:generate 10
```

Страница контроля процессов доступна по адресу `/report-processes`.

## Схема БД

Основные таблицы и поля названы по постановке задачи:
- `manufacturer`: `manufacturer_id`, `manufacturer_name`
- `product`: `product_id`, `product_name`, `category_id`, `manufacturer_id`
- `price`: `price_id`, `product_id`, `price`, `price_date`
- `process_status`: `ps_id`, `ps_name`
- `report_process`: `rp_id`, `rp_pid`, `rp_start_datetime`, `rp_exec_time`, `ps_id`, `rp_file_save_path`

Цены хранятся в минимальных денежных единицах: например, `10750` означает `107.50`.
